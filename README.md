# 쎈img 릴리스

쎈img(사진 일괄 편집·카드뉴스, Windows 10/11 64비트) 설치 파일과 자동 업데이트 정보를 올리는 공개 저장소입니다.
프로그램 코드는 여기에 없습니다.

## 받기
[최신 릴리스](https://github.com/smchosmart-beep/ssenimg-releases/releases/latest)에서 받으세요.

- **처음 설치하거나 0.18.0 이하를 쓰는 PC:** `SsenImage-Setup-<버전>-x64.exe` (전체 설치본)
- **설치된 PC를 직접 업데이트:** `SsenImage-<버전>-small.exe` (작은 업데이트, 앱 코드만 바꿈)
- **0.19.0 이상:** 쎈img가 새 버전을 알려 줍니다. 오른쪽 아래 알림에서 [업데이트]를 누르세요.

## 자동 업데이트 정보
- `ssenimg-update.json` — 최신 버전·파일 크기·SHA-256을 담은 매니페스트. Ed25519 전자서명이 붙어 있고, 쎈img는 앱 안의 공개키로 서명을 확인한 뒤에만 업데이트합니다.
- 쎈img는 업데이트를 확인할 때 이 저장소에서 버전 정보만 받아 옵니다. 사진이나 개인정보는 보내지 않습니다.
